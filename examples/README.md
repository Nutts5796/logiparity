# Examples

Start with [generic records](generic/): two local CSV files, no server, browser or database. The [suggest recipe](../docs/recipes/suggest.md) turns CSV/XLSX/saved JSON samples into a draft for explicit review. The [configuration reference](../docs/configuration.md) covers live REST, UI and SQL mapping.

Domain example packs use the same engine:

- [Delivery demo](demo/): synthetic API/export/browser parity and disruption scenarios.
- [Freight settlement](freight/): composite load/charge keys, filters, rollups and per-currency totals.
- [PostgreSQL](postgres/): a read-only database adapter example.
- [Staging](staging/): bring-your-own target and scenario mappings.
- [AI previews](ai/): optional local-first drafting workflows.

Existing example paths stay valid for published links.
