# @logiparity/ai

M5 optional provider-agnostic draft assistance: local request preparation, structured redaction, an OpenAI-compatible chat-completions adapter, local YAML validation and exclusive draft-file writes. No AI runs during normal Parity/scenario commands; CLI previews are local unless `--send` is explicit.

See [AI reference](../../docs/ai.md) and [synthetic input examples](../../examples/ai/README.md). No external AI SDK or new dependency version is added. This workspace is local/unpublished; provider output remains untrusted draft content for owner review.
