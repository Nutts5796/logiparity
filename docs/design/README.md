# Design previews

These HTML pages and screenshots record the selected variant E report and dispatcher design reference. They are preview-only pages that load web fonts from Google Fonts. They are excluded from the npm package and are not production reports. Their fixture values predate the current synthetic delivery seed.

Generated reports embed licensed fonts locally, apply a strict Content Security Policy and make no network requests. Their charts and totals are computed from the actual run. The source implementation also provides search, pagination and accessible text contrast.
