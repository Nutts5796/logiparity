# Studio design references

The owner selected these reference HTML files and screenshots for M9.1. They are copied unchanged from the supplied design folder. `report-E.html` includes the updated human labels and omits per-source lists below charts. Both HTML files load Google Fonts for preview only. Product reports and the demo embed licensed Latin subsets locally and make no font requests.

Reference data predates the realistic payout seed and the final-page pattern fix; product totals and chart membership are computed from each actual run. Production text colors are strengthened where required to meet 4.5:1 contrast. The working implementation uses pagination and searches all findings.
