## 3. Local setup drafts

`logiparity suggest` reads two to eight named CSV/TSV, explicit-sheet XLSX or saved JSON samples and prints a commented YAML draft. JSON supports root/data arrays or an explicit items JSONPath, suggesting unresolved REST endpoints. No API is called. Limits: 8 MiB per file, 200 columns, 1–1000 sampled rows (default 200), with truncation disclosed.

Drafts include candidate keys with observed uniqueness/presence, normalized-name/common-alias matches, every unmatched column, and evidence for number, money, date, datetime, enum and text guesses. Leading-zero IDs remain strings; empty/complex columns stay explicit; ambiguous normalized headers fail. Currency/unit/time-zone/mapping guesses retain TODOs. An unknown `TODO_REVIEW_REQUIRED` root property and unresolved key ensure an unreviewed draft fails validate. No field is silently dropped and no guess is silently accepted. New output files are private (0600), never overwritten, with paths relative to the output location. Inputs remain unchanged.

Offline CSV/JSON/XLSX fixtures cover mixed headers, aliases, thousands separators, dates, enum case variants, empty/sparse columns, unsupported shapes, limits and overwrite refusal. [configuration.md](../configuration.md) and the [suggest recipe](../recipes/suggest.md) explain review and usage.

Manual evidence in output/m12: the generic example found one R2 money difference ($20.00 → $20.01), exit 1; its unreviewed draft failed validation, exit 2, at explicit review/key/currency TODOs. A separate unpacked-archive smoke produced evidence-bearing CSV/JSON and CSV/XLSX drafts (exit 0); both failed validate (exit 2). That smoke used repository external dependencies; clean installed-package profiles are verified separately by test:package.
