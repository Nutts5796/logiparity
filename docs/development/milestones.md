# Development history

Milestone numbers identify owner-written implementation and acceptance specifications, rather than package versions. M1–M8 built the parity engine, adapters, scenarios, AI previews, CI and release tooling. M9 and its follow-ups refined packaging and reports. M10 added composite charge keys, filters, uniqueness, reassignment checks and optional adapters. M10.1 and M10.2 are review-fix milestones for the still-unpublished 1.1.0 release.

The dated entries below come from the repository commit history. The maintainer wrote milestone specifications and acceptance criteria, triaged review rounds and verified fixes. AI coding agents generated code, tests and documentation under the maintainer's commit account. A baseline dependency audit failure was reproduced; a separately reported consumer installation crash was not reproduced.
